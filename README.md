# Comparative Evaluation of spaCy and Transformer-Based Models for Named Entity Recognition

## 1. Project Overview

This project compares two approaches to Named Entity Recognition (NER):
- spaCy pretrained NER model
- A pretrained Transformer-based NER model

## 2. Objectives

- Understand how Named Entity Recognition works.
- Implement two pretrained NER systems.
- Evaluate both systems using the same test dataset.
- Compare entity-level precision, recall, F1-score, and inference time.
- Analyze errors and discuss the strengths and limitations of both approaches.

## 3. Technology Stack

- Python
- spaCy
- Hugging Face Transformers
- PyTorch
- pandas
- scikit-learn
- matplotlib

## 4. Project Structure

- `src/`: Model implementations and evaluation code
- `data/`: Dataset preparation and storage
- `results/`: Generated evaluation results
- `docs/`: Architecture and documentation

## 5. Evaluation

The models will be evaluated on the same test examples using compatible entity labels. Metrics and results will be documented after experiments are completed.

## 6. Reproducibility

The Python dependencies will be listed in `requirements.txt`. Instructions for setting up and running the project will be added as development progresses.
